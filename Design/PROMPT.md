# Промпт для Claude Code

Положи эту папку (`TZ-landing.md`, `PROMPT.md`, папку `reference/`) в папку будущего лендинга, открой её в VS Code и вставь в Claude Code текст ниже.

---

```
Сделай лендинг по ТЗ из файла TZ-landing.md.
Образцы дизайна: reference/mobile-390.html (телефон) и reference/desktop-1440.html (компьютер) — открой и изучи их, это точный вид, к которому нужно прийти. Размеры, отступы, цвета и SVG-иконки бери из них.

Стек: Astro + Tailwind CSS 4 (через @tailwindcss/vite), статичная страница, pnpm, без клиентского JS.

Работаем так:
1. Сначала прочитай ТЗ и образцы и покажи мне короткий план: какие файлы создашь и в каком порядке. Код пока не пиши — жди моего «ок».
2. После «ок» создай проект прямо в этой папке и сверстай по плану.
3. Запусти pnpm build и убедись, что сборка без ошибок.
4. Сверь страницу с образцами на ширине 390 px и 1440 px и проверь, что от 320 до 1920 px нет горизонтальной прокрутки. Исправь расхождения.
5. Сверь все тексты с ТЗ — они должны совпадать слово в слово.
6. Сделай git-коммит «Лендинг Personal CRM: первая версия».

В конце коротко напиши, что сделано, и как мне запустить лендинг у себя (команда и адрес в браузере).
```
