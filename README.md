# Personal CRM — лендинг

Одностраничный сайт Personal CRM. Одно целевое действие — кнопка «Перейти в приложение».

## Запуск у себя

1. Один раз установить зависимости: `pnpm install`
2. Запустить: `pnpm dev`
3. Открыть в браузере: http://localhost:4321

Страница обновляется сама, когда меняются файлы. Остановить — `Ctrl+C` в терминале.

## Сборка

- `pnpm build` — готовый сайт появится в папке `dist/`
- `pnpm preview` — посмотреть собранную версию на http://localhost:4321

## Выкатка

Адрес: https://web.vladmath.com

Каждый push в ветку `main` - это выкатка. GitHub Actions сам собирает `dist/`, заливает её на сервер в `/var/www/web.vladmath.com` и проверяет, что сайт отдаёт новую версию. Ход выкатки - вкладка Actions на GitHub, обычно 1-2 минуты.

Отката нет: если что-то сломалось - правим и выкатываем новую версию.

На сервере лендинг заливает отдельный пользователь `landing`: его ключ может только записывать файлы в папку лендинга, больше ничего.

## Где что менять

- Ссылка на приложение — `src/config.ts` (`APP_URL`)
- Цвета, шрифты, размеры текста, отступы — `src/styles/tokens.css`
- Тексты и блоки страницы — `src/components/`, по файлу на блок
- Макет и ТЗ — папка `Design/`

## Стек

Astro, Tailwind CSS 4, pnpm. Статичная страница без JavaScript в браузере.
