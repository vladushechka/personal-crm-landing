# Personal CRM — лендинг

Одностраничный сайт личной CRM. Одно целевое действие — кнопка «Перейти в приложение».

## Запуск у себя

1. Один раз установить зависимости: `pnpm install`
2. Запустить: `pnpm dev`
3. Открыть в браузере: http://localhost:4321

Страница обновляется сама, когда меняются файлы. Остановить — `Ctrl+C` в терминале.

## Сборка

- `pnpm build` — готовый сайт появится в папке `dist/`
- `pnpm preview` — посмотреть собранную версию на http://localhost:4321

## Где что менять

- Ссылка на приложение — `src/config.ts` (`APP_URL`)
- Цвета, шрифты, размеры текста, отступы — `src/styles/tokens.css`
- Тексты и блоки страницы — `src/components/`, по файлу на блок
- Макет и ТЗ — папка `Design/`

## Стек

Astro, Tailwind CSS 4, pnpm. Статичная страница без JavaScript в браузере.
